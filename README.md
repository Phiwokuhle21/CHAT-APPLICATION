Login System - Student Assignment

Overview
This is a comprehensive login and registration system that validates user credentials according to specific requirements.

Features
- Username validation (must contain underscore, max 5 characters)
- Password complexity validation (8+ chars, capital, number, special character)
- South African cell phone validation with international code (+27)
- User registration with validation
- User authentication (login)
- Comprehensive unit tests
